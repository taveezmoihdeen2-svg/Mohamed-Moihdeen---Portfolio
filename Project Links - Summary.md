# Network Security

**Azure Network Security Lab**

A hands‑on lab designed to demonstrate core Azure networking and security skills. # Azure Secure Network Architecture Lab

**Overview**
This project demonstrates the design and implementation of a secure Azure network architecture using Microsoft Azure networking services. The environment simulates a production deployment by separating workloads into dedicated virtual networks and subnets while implementing layered security through Network Security Groups (NSGs), User Defined Routes (UDRs), Virtual Network Peering, and a Network Virtual Appliance (NVA).

The objective of this project was to gain hands-on experience with Azure networking, traffic routing, and cloud security concepts commonly used in enterprise environments.
